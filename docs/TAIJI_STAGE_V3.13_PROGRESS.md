# 太极 v3.13.0 阶段报告

日期：2026-08-04

## 阶段定位

本版本继续 `v3.6 -> v4.0` 自主智能体路线，重点不是增加固定通道，而是把模型提出的行动接入统一、可审计的决策权校验，并补齐长期记忆的四类边界。

## 已完成

### 自主行动提案进入真实执行前门禁

- 新增 `autonomousDecisionAuthority`，统一描述行动来源、当前目标、计划版本、责任步骤、工具、风险、授权和预期证据。
- 模型或运行时负责提出行动，确定性内核只验证目标、计划、依赖、权限、预算和证据边界。
- 助理、员工私聊和团队成员在真实工具调用前记录行动提案；过期目标、过期计划、废弃步骤和依赖未满足会被拒绝。
- 没有新提案时保留确定性回退，不生成看似智能但没有来源的虚假决定。

### TaskService 与收尾职责继续拆分

- `taskServiceRecoveryCommands.cjs`：步骤失败、审查返工、自适应改计划和重新分配。
- `agentLoopFinalization.ts`：Agent Loop 最终状态、用户可见交接与完成判断。
- `teamAutonomousDecision.ts`：团队责任员工的真实工具行动提案。
- `taskService.cjs` 约 477 行，`createTaskService` 约 180 行；Agent Loop 主函数约 730 行。

### 四类记忆成为正式数据协议

- 情景记忆：一次任务、决定或历史事件。
- 语义记忆：仍有效的稳定事实、约束和项目知识。
- 程序记忆：经过真实验收证明可复用的操作方法。
- 用户偏好：老板长期稳定的沟通和工作偏好。
- schema v1 数据加载后自动迁移到 v2，不删除原内容；查询、上下文注入、同步配置和 Markdown 投影保留新类型。
- 记忆中心可按四类筛选，并在新增记忆时明确类型。

### 程序记忆验收门槛

- 自动任务复盘只有在任务状态为完成且存在真实验证证据时写入程序记忆。
- 员工步骤必须有本步骤验证证据，单纯工具成功不够。
- 旧版任务经验缺少可核对验收时迁移为情景记忆，避免错误路线获得“已证明有效”的地位。
- 独立审查模型提出程序记忆但当前任务未通过真实验收时，会降级为情景记忆并等待审核。

### 人格同步

- 内置章北海人格升级为 v26。
- 新增自主决策权、真实工具动作绑定、完成证据门禁和四类记忆协议。
- 助理聊天、助理设置和总设置入口统一使用 v26 迁移附录；旧自定义人格只追加缺失协议。
