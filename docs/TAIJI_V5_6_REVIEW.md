# 太极 V5.6.0 版本复盘

日期：2026-08-07

## 本版结论

V5.6.0 已完成“统一记忆账本与项目边界”的第一阶段。它解决的是长期学习的事实来源和项目串台风险，不是继续给模型增加提示词，也没有提前把自动生成 Skill 宣传成已经可靠。

## 完成项

- 主进程记忆账本升级到 schema v4，新增 `project` 记忆范围、`memoryId`、证据 ID、来源任务、状态、替代关系、历史恢复与引用记录。
- 记忆检索按当前项目、团队、员工、会话和任务范围返回正文、记忆 ID、命中理由和分数；引用记录写入账本，并在助理/员工聊天任务中登记为任务引用。
- 项目范围记忆不会进入其他项目。带项目 ID 的团队/员工经验也只在同项目中返回。
- 旧用户画像、旧长期记忆、旧任务经验不再从浏览器存储直接注入聊天或任务决策。旧任务经验只读迁移为 `legacy`，默认不参与模型上下文。
- 对话洞察提炼改成用户可审核的提案；组织、用户、项目和未验收经验不允许策略自动批准。
- 设置页可按项目查看记忆，查看历史版本、恢复被替代版本、核对证据数量和最近检索记录。
- 章北海内置人格升级到 v27，明确项目隔离、当前事实优先、引用可追溯和 Skill 候选仍需验证/审批。

## 验证证据

- `npm.cmd run verify:v56`：通过。
  - 项目隔离、引用审计、版本替代、回滚、旧经验隔离、自动批准边界和重启一致性。
  - 分层记忆既有回归。
  - 任务复盘既有回归。
  - TypeScript 与生产构建。
- `npm.cmd run test:run`：54 个测试文件、184 项测试通过。
- `npm.cmd run lint`：通过，无保留警告。

## 本版没有做什么

- 未接入向量数据库；先保证事实源、项目边界和解释链可靠。
- 未自动安装或自动发布任何新 Skill。
- 未实现跨任务候选聚合、Skill 编译、安全扫描、样例演练和灰度回滚；这些属于 V5.7。
- 未做 20 至 30 个真实长期任务评测；这些属于 V5.8。

## 下一版唯一重点

V5.7 只做“Skill 候选、编译、验证与灰度”。先要求多个独立成功任务与真实证据形成候选，再生成草案、验证、人工审阅和灰度发布；不提前混入 V5.8 的长期评测工作。
