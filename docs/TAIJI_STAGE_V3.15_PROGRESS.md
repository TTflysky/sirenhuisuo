# 太极 v3.15.1 阶段报告

日期：2026-08-05

## 本轮定位

本轮承接 `TAIJI_V3_TO_V4_ROADMAP.md`，先完成 v3.15.0 的内核基线，再把已审核通过的 HTML Demo 逐项迁移到生产界面，确保视觉验收不再出现“Demo 精致、客户端粗糙”的偏差。

## 已完成

- **长任务驻留**：新增 `src/engine/taskResidencyCheckpoint.mjs`。检查点保存任务身份、目标哈希、计划 ID/版本/哈希、已完成步骤、已验证证据、下一可执行步骤、上下文摘要哈希和 Worker 检查点序号。
- **恢复闸门**：`electron/taskWorker.cjs` 在会话更换或租约失效时校验全部驻留字段；原生适配器且检查一致时自动排回队列，目标/计划/证据/上下文冲突时安全暂停。
- **继续语义**：用户主动继续可以基于当前真实状态重建恢复基线；已完成步骤不会因重启或继续被重新打开。新 TaskService 默认建立恢复上下文，旧任务领取时兼容补齐。
- **上下文一致性**：驻留摘要哈希纳入 Turn Lifecycle 上下文压缩次数、摘要、未决问题和用户插话，避免“状态说在恢复、上下文已经漂移”。
- **通用语义验收**：网页验收工具增加 `semanticChecks`，支持 `group`、`order`、`adjacent`、`grid` 和 `interaction`。结果按视口返回元素描述、期望值和失败原因，与截图、边界和运行错误统一阻断交付。
- **真实回归**：错误排列网格被拒绝，修正后五种语义契约通过；无界面长任务回归跨两个 Worker 会话恢复，检查点连续 `1 -> 5`，上下文压缩 2 次、用户插话 2 条均保留。
- **窗口层级**：锁定助手或聊天窗口时使用系统级置顶；主窗口获得焦点、窗口重建和显式打开不会再把锁定窗口压到后面，解除锁定恢复普通层级。
- **窗口控件一致性**：助手、员工私聊和团队聊天窗口的锁定、最小化、最大化、关闭控件统一为与主界面相同的 `34 x 34px` 正方形；固定最小尺寸和 flex 基准，避免标题栏高度或主题边框再次把控件拉成长方形。
- **HTML Demo 完整对齐**：Pop 主题生产根布局取消窗口内缩，标题栏固定 `62px`，主分界 `4px`、次级控件 `3px`，标题栏交互控件固定 `34 x 34px`，面板/控件圆角分别为 `16px/12px`；办公室、员工牌、聊天、设置、诊断和弹层共用 Demo 的网点、阴影、颜色和按钮层级。
- **跨主题可读性**：记忆和诊断标签在酸性暗黑下明确使用高对比前景色；原版商务、Pop、Acid 的布局边界互不串色，Pop 的十套配色和 Acid 的四套配色都沿用同一组件规则。
