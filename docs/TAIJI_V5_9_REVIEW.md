# 太极 v5.9.0 统一运行轨迹与监控台复盘

## 目标

将任务账本、原生执行、Worker 与操作诊断投影到唯一的脱敏遥测事件账本，让真实陪跑能回答“任务现在在做什么、最近的真实动作是什么、为什么停下、已经产生了什么证据”。

## 已完成

- 追加式 `telemetry-events.jsonl` 账本、查询、摘要、保留上限与重启读取。
- 任务账本、Worker、原生执行器、操作诊断的事件适配。
- 设置 -> 诊断中心的实时运行监控台与脱敏问题包导出。
- Token、耗时、错误分类、执行者、模型、工具、任务与项目关联的公开字段。
- V5.9 专项验证，以及 V5.6-V5.8、性能与 Electron 驻留回归。

## 不能夸大的结论

- 这不是隐藏思维链展示，也不会保存 provider 的 `reasoning_content`、提示词、密钥或附件正文。
- 这不是第二套任务状态或产物系统；任务和产物仍从既有账本读取。
- 这不是自动根因分析。监控台提供完整、可导出的事实，再由下一阶段基于跨项目样本建立通用告警。

## 已知缺口

- 团队提案和成员调度、部分旧渲染器路径、模型请求细节尚需继续接入结构化事件。
- 真实客户端长驻与多账户证据仍需要实际使用积累。

## 验收证据

- `npm.cmd run verify:v59`：通过。
- 包含 V5.9 遥测脱敏与恢复验证、24 项自治回放、V5.6/V5.7 记忆与 Skill 生命周期、性能回归、12 窗口 Electron 驻留、Lint 和生产构建。
