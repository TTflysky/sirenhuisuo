# 太极 v3.14.0 阶段报告

日期：2026-08-04

## 本轮定位

本轮没有增加新的固定流程或案例关键词，而是把已有自主决策权落实到真实工具执行边界。模型继续负责理解目标和选择行动；确定性代码只校验目标、计划、责任、依赖、授权与证据范围。

## 已完成

- 新增 `autonomousExecutionGate`，统一核对 `goalId`、计划版本、责任步骤、责任员工、工具和授权提案。
- 助理与员工私聊通过 `taskServiceBridge` 在工具执行前消费门禁；聊天任务的通用执行步骤现在拥有明确责任员工。
- 团队成员工具调用与交接文件读取共用 `teamAutonomousDecision`，直接读取不再绕过主持层。
- 原生后台执行器在工具、动态委派和 Git Worktree 动作执行前，将模型选择写入任务账本并由同一门禁校验。
- 错误责任员工、未完成依赖、过期计划、错误工具名和未接受提案均有回归覆盖。
