# 太极波普漫画风 UI 设计基线

## 目标

本轮不是给旧界面换皮，而是在保留现有操作习惯的前提下，建立一套可以长期扩展的产品界面结构。HTML Demo 只验证方向，不修改 React/Electron 生产界面。

## 信息层级

### L0：应用外壳

- 标题栏只承担品牌、一级视图切换、系统状态和窗口操作。
- 一级视图固定为办公室、数据分析、团队大厅、技能库。
- 设置属于全局操作，不进入任何业务页面内部。

### L1：工作导航

- 左侧工作台只放助理、团队、员工和对应的新建入口。
- 搜索只过滤当前对象列表，不改变主页面目标。
- 窄窗口收成图标栏，但不影响聊天和任务继续执行。

### L2：页面上下文

- 页面头部只说明当前位置、对象总量和总体状态。
- 分类导航只负责快速筛选，不混入新建、设置或诊断操作。
- 办公室内容区只展示员工工牌和实时状态。

### L3：核心工作区

- 聊天主列只保留用户消息、智能体总结、审批和输入。
- 实时执行区最多展示四行短报告，成功记录自动收起。
- 用户随时插话，新消息优先进入当前任务判断。

### L4：任务观察

- 右侧只回答四个问题：谁在做、正在做什么、依赖谁、用什么证据验收。
- 状态必须区分执行中、等待前置、等待用户、已完成、失败和停止。
- 产出物、任务回放、暂停、继续和停止都属于任务观察，不进入聊天气泡。

### L5：决策与风险

- 只有真正需要用户选择时才显示高亮审批卡。
- 审批卡必须写明目标、影响、责任成员和批准后的下一步。
- 危险操作、外部发送、付费、删除和敏感授权继续遵循安全审批策略。

## 视觉系统

- 背景：暖白纸张与细密半调点阵，避免大面积刺眼纯白。
- 轮廓：主要容器和卡片外框使用 4px 黑线，次级控件与内部虚线使用 3px，标签与状态细线至少 2px。
- 阴影：3px 或 5px 硬偏移阴影，不使用模糊悬浮阴影。
- 红色：主动作、警示和需要注意的状态。
- 黄色：审批、活动状态和阶段重点。
- 青色：选中、信息与导航反馈。
- 绿色：已完成、在线和验证通过。
- 员工卡片、聊天气泡和审批面板采用 16px 圆角，功能面板采用 14-16px，按钮与输入框采用 10-12px，状态标签使用胶囊圆角；保留黑色描边但明显减少生硬直角。
- 不使用装饰性渐变球、玻璃漂浮卡和超大海报标题。

## 互动音效

- 提供 FC、Mac、街机三套操作音色，默认使用 Mac 音色。
- 音量默认 80%，用户可以在标题栏音效面板中即时调节。
- 提供独立总开关；关闭后保留音量和音色设置，但所有交互保持静音。
- 普通点击、选择切换、批准成功和危险操作使用不同的短反馈。
- 音效由浏览器音频引擎即时合成，不依赖网络音频文件。
- 音量为 0 时完全静音，界面操作不受音频状态影响。

## 配色主题

- 保持统一的波普漫画布局、16px 圆角和粗黑描边，只切换纸张底色与功能色。
- 内置经典波普、黑白网点、复古印刷、海盐汽水、薄荷草莓、柑橘天空、街机霓虹、蓝图工坊、芒果海岸和报刊油墨 10 款主题。
- 使用颜色块直接预览，选择后即时生效并记住上次使用的主题。

## 核心组件

- 员工工牌：正面显示头像、姓名、职位、状态、摘要和三项能力；背面显示详细能力与私聊入口。
- 聊天气泡：用户使用青色，智能体使用白色，成功结果使用浅绿色。
- 审批卡：黄色主体、红色主操作、明确的待批准状态。
- 实时执行：黑底四行短报告，详细日志继续折叠保存。
- 任务观察：阶段顺序、负责人、依赖、进度和产出物保持在同一视觉区域。

## 响应式规则

- 宽屏：左侧导航、会话/成员栏、消息流、任务观察同时展示。
- 中等窗口：左侧导航收成图标栏，会话/成员栏隐藏，任务观察保留。
- 窄窗口：任务观察折叠为边缘入口，消息和输入保持完整宽度。
- 分类导航始终可以横向滚动，员工工牌区域始终可以纵向滚动。

## 正式迁移边界

1. 先建立主题令牌和共享基础组件。
2. 再迁移办公室与员工工牌。
3. 然后统一助理、员工私聊和团队聊天外壳。
4. 最后迁移审批、实时执行、任务观察和产出物。
5. 每一步都保留现有业务逻辑和可回退版本，视觉迁移不夹带调度内核重构。

## 验收标准

- 所有页面一眼可判断当前位置、当前对象和主要动作。
- 同一层级的控件在助理、员工私聊和团队聊天中保持一致。
- 1440x900 与 900x720 下无横向溢出、无遮挡、无损坏头像。
- 完成、等待、失败和需要用户确认不能使用相同视觉状态。
- 产品功能优先于装饰，波普风格不能降低长时间工作的可读性。

## 三套可切换视觉风格

### 原版商务

- 保留太极原有的轻量办公气质，使用浅灰蓝背景、白色内容面与低饱和蓝色强调。
- 主要边界统一为 1px，使用柔和层级阴影，不使用网点纹理和硬偏移阴影。
- 恢复生产客户端已有的 11 套配色：明亮、深色、护眼、柔和灰、海湾蓝、静谧蓝、玻璃晨光、玻璃深夜、云杉绿、石墨和霓虹赛博。
- 深色商务主题按组件语义翻转文字颜色，审批、实时执行、任务观察、产出物和回放控件不得出现浅底浅字。
- 适合长时间办公、企业演示以及内容密度较高的工作场景。

### 波普漫画

- 使用已经验收通过的 4px 主描边、3px 次级描边、半调网点和圆润工牌。
- 内置 10 款独立配色，员工工牌、聊天、审批和任务观察必须同步跟随配色。
- 保留 FC、Mac、街机三套交互音效，默认 Mac、音量 80%。

### 酸性暗黑

- 以炭黑和深灰作为长期工作底色，荧光黄绿色只用于当前选中、关键状态与主要操作。
- 参考 Awwwards 的强留白、杂志式大标题与精细数据边界，但不改变太极的办公工具布局。
- 卡片与面板使用 1px 深灰边界、克制暗色阴影和微弱网格，不使用大面积发光与装饰性光球。
- 酸性暗黑工牌不显示顶部挂带色块，卡片从完整顶边开始；另外两套风格保持各自既有工牌处理。
- 提供核能青柠、电击洋红、液态冰蓝和警戒橙 4 套信号配色，深色内容面和信息层级保持不变。
- 浅绿背景上的文字统一使用近黑色，深色内容面的正文对比度保持可读。

## 风格切换规则

- 标题栏的“界面风格”入口用于切换原版商务、波普漫画和酸性暗黑。
- 当前风格写入本地设置，刷新或重新打开 Demo 后继续沿用。
- 配色面板根据当前风格动态显示：原版商务 11 款、波普漫画 10 款、酸性暗黑 4 款。
- 三种风格分别保存自己的最后一次配色，切换风格时恢复该风格上次使用的主题。
- 风格只改变视觉令牌与动效表达，不改变办公室、员工、团队、聊天、审批和任务观察的信息结构。
